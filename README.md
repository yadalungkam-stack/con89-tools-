# CON89 ทะเบียนเครื่องมือ — หน้าเว็บ

หน้าเว็บของระบบเบิก-คืนเครื่องมือ CON89 ซึ่งรันบน Google Apps Script

- `index.html` หน้าเว็บทั้งหมด Apps Script ดึงไฟล์นี้ไปแสดงทุกครั้งที่มีคนเปิด (แคช 1 นาที)
- `photos/` รูปเครื่องมือชุดแรก ใช้นำเข้าเข้า Google Drive ตอนตั้งค่าครั้งแรกเท่านั้น

ข้อมูลเครื่องมือและประวัติการเบิกเก็บใน Google Sheet ส่วนตัวของเจ้าของ ไม่อยู่ใน repo นี้
